# Portfolio – Syed Abrar Reshad

[Visit the live portfolio](https://abrarreshad.vercel.app/)

This responsive portfolio was built with React and Vite, styled with Tailwind CSS, and animated with Framer Motion. Its sections present my introduction, background, skills, projects, and contact details. Portfolio content is organized in `src/data.js`, while reusable page sections and interactive elements are built as React components.
